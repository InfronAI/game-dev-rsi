# Creator brief
Implement a playable browser game with keyboard and button controls. Serve index.html over local HTTP. Export map, start() and step(state, action) from logic.mjs. The map and state schema are illustrated by the playable reference in assets/reference. Actions are up, down, left, right and reset. State fields are x, y, power, relays (unique coordinate strings in collection order) and phase (active, drained or won). Keep transitions deterministic. Implement your candidate in the round workspace. Record which reference materials or starter files you used. For an independent implementation, use the behavior specification and observe the reference by playing it; document any source access. Run both public suites after every change.
